# DEPLOY
## Environment Setup
1. **Prerequisites:** Windows, Visual Studio / MSVC for C++ compilation, CMake.
2. **Submodules:** Ensure all submodules are initialized (`git submodule update --init --recursive`).
3. **Build Instructions:** Use CMake to generate the project files for the `engine` directory, then compile the `torque` executable.
4. **Running:** Execute `start.bat` or run the compiled executable pointing to the `game` directory.
